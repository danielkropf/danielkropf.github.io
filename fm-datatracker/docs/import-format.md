# Formato de importação

CSV com cabeçalhos é aceito; delimitador e BOM são tratados pelo Papa Parse. O preview sempre mostra arquivo, tipo, data, linhas, colunas ignoradas e avisos.

A data do snapshot é sempre preenchida manualmente e é obrigatória. O sistema não infere datas pelo nome do arquivo. CA, PA, Ability, Potential, Current Ability e Potential Ability são preservados no bruto e ignorados no scoring.
