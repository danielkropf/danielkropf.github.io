# Formato de importação

CSV com cabeçalhos é aceito; delimitador e BOM são tratados pelo Papa Parse. O preview sempre mostra arquivo, tipo, data, linhas, colunas ignoradas e avisos.

Profile Numancia inicial: `Squad YY` → 01/07/20YY; `Squad YY-ZZ` → 01/01/20ZZ; `Stats` segue a mesma regra; `Intake YY` → 12/04/20YY. A data pode ser corrigida antes da confirmação. CA, PA, Ability, Potential, Current Ability e Potential Ability são preservados no bruto e ignorados no scoring.
